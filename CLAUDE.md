# Traveller Perks: project rules

- No emojis anywhere: UI, copy, emails, commit messages.
- Label every CSS block: `/* // CSS NAME: block-name // */`.
- Brand: teal #4ECAC2 / #00ADBC, navy #123B4A, ink #0E1417. Text on teal or orange is always white. Never ink text on orange.
- Display font Work Sans 900, uppercase headings.
- Copy says "Group Tour" and "Group Leader" (capitalised).
- Venue-facing copy is for all East Coast backpackers and working holiday makers, not only ULTIMATE customers.
- Never show phone numbers as plain text. Contact goes through the email contact pop-up (info@ultimate.travel).
- Images for production must be self-hosted (Supabase Storage), not hotlinked.
- The owner is not a developer: explain setup steps plainly, click by click.
- Keep demo mode working when Supabase keys are missing.
